# Assets

Everything here is either generated by a script in `scripts/` or a placeholder waiting for
a real screenshot. Both the README and the website read from this one directory, so an
asset only ever exists once.

| File | What it is | How to regenerate |
| --- | --- | --- |
| `led-strip.gif` | The eight-LED strip cycling through real preset programs. A simulation, not footage. | `scripts/make_led_gif.sh` |
| `app-popover.png` | **Placeholder** — the menu-bar popover, 920 × 1040 (460 × 520 pt @2x) | `python3 scripts/make_placeholders.py` |
| `app-modes.png` | **Placeholder** — the Modes tab, 920 × 900 | same |
| `app-activity.png` | **Placeholder** — the activity window, 880 × 960 | same |

## Replacing a placeholder

Overwrite the file, keeping the same name and — ideally — the same pixel size, so nothing
around it reflows. The dimensions above are the app's real window sizes at 2×:
`ContentView` is `.frame(width: 460)` and `ActivityView` is `.frame(width: 440, height: 480)`.

Capturing a menu-bar popover is fiddly, because it closes the moment it loses focus.
Two approaches that work:

- **`⇧⌘5` → Capture Selected Portion.** Start the capture, then click the menu-bar icon to
  open the popover — the crosshair does not steal focus from it. Drag around the popover
  and shoot.
- **`⇧⌘4` then Space** hovers a window picker, but it will not see the popover, so use the
  region form above instead.

Turn off *Show shadow* (or use `⌥` while shooting) if you would rather not have the drop
shadow baked in — the page already frames the image.

Then drop the file in here and commit. Nothing else needs changing.

## Keeping this directory small

Raster assets committed to git are there forever, so keep an eye on size. The GIF is the
only large file and is deliberately held under 1 MB, which is why it uses a tight bloom and
no dithering — see the comments in `scripts/make_led_gif.sh` for why that combination and
not another.
